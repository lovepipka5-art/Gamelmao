# «Ну и выбор» — MVP v1

Мобильный веб-прототип игры с двумя вариантами дилеммы, локальной статистикой и серверным endpoint для генерации новых дилемм через OpenAI API.

## Что уже есть

- Адаптивный мобильный интерфейс в мемном тёмном стиле.
- Две карточки с отдельными блоками «Ты получаешь» и «Но есть нюанс».
- Голосование, история выборов и статистика в `localStorage`.
- Кнопка «Ещё дилемму» и системная функция «Поделиться».
- Серверный endpoint `POST /api/dilemma`.
- API-ключ читается только из серверного `.env`, не отправляется клиенту.
- До трёх попыток генерации с базовыми проверками качества и повторов.
- Деморежим, если ключ ещё не настроен.

## Запуск локально

Требуется Node.js 18+.

```bash
npm install
cp .env.example .env
```

Откройте `.env` и вставьте собственный API-ключ:

```env
OPENAI_API_KEY=your_api_key_here
OPENAI_MODEL=gpt-4.1-mini
PORT=3000
```

Запуск:

```bash
npm start
```

Откройте http://localhost:3000 на компьютере или телефоне в той же сети (для телефона используйте локальный IP компьютера вместо `localhost`).

Если `OPENAI_API_KEY` не указан, интерфейс работает в демонстрационном режиме с примерами. Для настоящей генерации требуется действующий API-ключ и доступ к выбранной модели. API оплачивается отдельно от подписки ChatGPT.

## Ограничения прототипа

- История семантических повторов хранится в памяти сервера: при перезапуске она сбрасывается, несколько экземпляров сервера не делятся историей.
- Проверка повторов на основе пересечения слов — стартовый фильтр, а не полноценная семантическая модель. Для публичного запуска рекомендуется база данных и семантические эмбеддинги.
- Статистика хранится в браузере и не синхронизируется между устройствами.
- Пока нет аккаунтов, рейтингов, модераторской панели, PWA-установки и защиты от злоупотребления API.
- Перед публичным запуском нужно добавить rate limiting, ограничения стоимости, логирование ошибок, модерацию и тесты генератора.
